# Kitely 🪁💨

## All in one wind visualizer app to help you fly kites with ease, packed with useful features and a clean UI.

🔒 **Privacy First: This app does not store or distribute any location information to third parties, the co-ordinates are used to fetch weather information from the free and open source library OpenMeteo.**

### Features

This android application allows you to see and visualize various wind metrics that need to be taken into account when flying a kite:

* You can scout out wind speeds at prospective kite-flying areas using precise co-ordinate inputs, and even save these as presets.

### Installation and Specifics

_⚠️ This App is only for Android 7.0 (Nougat) and above_

1. Download the APK from the Releases Section
2. Begin the Install, and you will be prompted with a security notification
3. Click the small arrow and select install anyway.

! IF YOU ARE A BETA TESTER, and already have an unsigned .apk of Kitely installed:

1. Navigate to Settings > Apps > Kitely and hit uninstall
2. Then begin the installation of the signed .apk file attatched to this repo
